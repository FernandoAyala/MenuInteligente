## 🧠 **INTELIGENCIA AVANZADA**

### **🎯 Pedidos Directos Inteligentes**
El sistema reconoce **patrones naturales de pedido**:

| Patrón | Ejemplos | Resultado |
|--------|----------|-----------|
| **"Quiero..."** | *"Quiero una pizza margherita"* | Busca pizza margherita en el menú |
| **"Me gustaría..."** | *"Me gustaría un café grande"* | Busca café en opciones disponibles |
| **"Pido..."** | *"Pido dos hamburguesas"* | Busca hamburguesas con cantidad |
| **"Dame..."** | *"Dame una ensalada césar"* | Busca ensalada césar específica |

### **🔢 Reconocimiento de Cantidades**
El sistema entiende **cantidades automáticamente**:

| Formato | Ejemplos | Resultado |
|---------|----------|-----------|
| **Números** | *"2 pizzas"*, *"3 cervezas"* | Procesa cantidad numérica |
| **Palabras** | *"dos tacos"*, *"tres empanadas"* | Convierte palabras a números |
| **Expresiones** | *"un par de..."*, *"media docena..."* | Interpreta expresiones comunes |
