# Servicios de API

El directorio "services/api/" contiene los servicios para comunicación con la API backend del proyecto Menu Inteligente.

## Estructura

```
src/services/api/
├── client.ts                 # Cliente HTTP configurado (axios)
├── chatService.ts            # Servicio de chat conversacional
├── llmService.ts             # Servicio de gestión LLM
├── recommendationService.ts  # Servicio de recomendaciones
└── index.ts                  # Exportaciones centralizadas
```
